# 公开计算模块

`excel-analysis.js` 是与站点 `docs/assets/excel-analysis.js` 字节一致的纯 JavaScript 模块，采用 UMD 导出，既可供浏览器使用，也可在 Node 中复核。不依赖大模型 API。

`parseWorkbook(workbook, XLSX)` 读取标准模板并执行日期、数值、单位与重复值检查；`analyze(dataset, date)` 返回指标、图表序列、规则文本及判断边界。仅标准模板分发，私有来源映射已剥离。

- WoW / 4W / 3M：不晚于分析日减7日、28日、3个自然月的最近有效观察为基期。
- MoM / YoY：对应上一自然月、上一年同月；月度缺失不估算。
- 趋势：近4周大于2%为上行、小于-2%为下行，其余为震荡。
- 共振：DXI与DRAM的4周趋势均上行为同步改善，均下行为同步走弱，其余保留分化或数据不足。
- 图表：共同起点100用于不同量纲比较，原始数值不缩放。
- 边界：基期与当前观察必须不同，分母大于0；同日冲突隔离，不用未来数据。

静态快照来自随附 SAMPLE 模板。同一份标准模板可在浏览器重新计算，便于复核结果。修改本模块后同步其站点副本；不另造重复的分析引擎文件。

Python、Pandas、SQLite 与 Streamlit 属于私有开发版的研究工作流，不在本公开仓库内提供。这里不宣称公开版包含未分发的底层实现。
